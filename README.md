# CVL for Office

[English](#english) | [中文](#中文)

## English

Chinese Variants Linter for Office. It detects mixed Simplified / Traditional Chinese characters and Mainland / Taiwan / Hong Kong terminology in a document, and lets you fix them one by one.

## 中文

Chinese Variants Linter for Office. 检查文档中混用的简体 / 繁体字形与两岸三地用词，并逐条替换。
